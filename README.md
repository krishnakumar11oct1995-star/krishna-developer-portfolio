# Krishna Kumar — Developer Portfolio & Resume Website

> Modern, responsive developer portfolio showcasing enterprise Salesforce engineering, AI automation, and full-stack projects.

## 🚀 Features
- **Interactive Skills Matrix:** Visual tech proficiency radar across Salesforce, Web, AI, and Cloud platforms.
- **Project Case Studies:** Deep-dive modal views into architectural implementations.
- **Discoveries Module:** Lightweight file-based CMS rendering technical articles from Markdown.
- **Obsidian Dark Theme:** High-contrast, clean developer aesthetic.

## 🛠️ Tech Stack
- React 18 + Vite 6
- Tailwind CSS & Lucide Icons
- Marked & Prism.js
